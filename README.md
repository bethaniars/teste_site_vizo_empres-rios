# Site Negócios que merecem ser vistos

Página única e estática (HTML, CSS e JS em um só arquivo, imagens embutidas).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `site`).
2. Envie `index.html` e `.nojekyll` para a raiz do repositório (Add file > Upload files).
3. Vá em Settings > Pages. Em Source escolha "Deploy from a branch", branch `main` e pasta `/ (root)`. Salve.
4. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Domínio próprio
Em Settings > Pages > Custom domain, informe o domínio e aponte o DNS para o GitHub Pages.
